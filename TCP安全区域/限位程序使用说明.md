# UR5 TCP 极限区域软件限位

主模块：`E:/学习/ur5_limit_safety.py`。已接入 `main.py`、`ur5_move_ab.py` 和 `ur5_move_base_z.py`。

采用四个标定点的 Base-XY 投影作为四边形边界，包含边界、余量为零；Base-Z 必须大于等于 0 mm，上限未指定。原始标定点 Z 不参与底面计算。标定和运行必须使用同一机器人 Base 和正确的活动 TCP。

## 实现行为

- 电脑端：检查手动输入的目标和 A/B 坐标，越界或非有限值直接拒绝。
- 控制器端：启动时要求静止且实际 TCP 在允许区域内。不会自动把界外 TCP 拉回区域。
- 每段运动前：检查实际 TCP、目标坐标及控制器的 `is_within_safety_limits`。
- 运动采用保持姿态的 `movel`，禁用圆角（r=0）。四边形区域是凸集，所以区域内两点间的理想直线也在区域内。
- 主线程按 `sync()` 周期检查实际 TCP。发现越界，先终止运动线程，再执行 `stopl(0.5)` 减速并 `halt`，不自动重启。
- 运动结束后监控随程序结束。这不是电脑后台服务，不能约束未经过此模块的程序、示教器点动或自由拖动。

## 本地使用

在 PowerShell 中执行：

```powershell
cd E:\学习
# 检查点，输出 INSIDE 或 OUTSIDE，不连接机器人。
python .\ur5_limit_safety.py --check-mm 0 -300 100

# 只预览到指定目标的受限直线运动，不连接机器人。
python .\ur5_limit_safety.py --target-mm 0 -300 100

# 预览已接入限位的 A/B 搬运和 Z 抬升程序。
python .\ur5_move_ab.py --preview
python .\ur5_move_base_z.py

# 运行离线测试，不连接机器人。
python -m unittest -v test_ur5_limit_safety
```

显式向控制器发送目标运动的命令格式如下；执行时仍需输入 YES：

```powershell
python .\ur5_limit_safety.py --target-mm 0 -300 100 --execute 192.168.1.10
```

上述坐标仅用于展示命令格式，不表示该路径已检查无碰撞。既有 `main.py` 和 `ur5_move_ab.py` 保留原有发送方式及 YES 确认。

## 验证范围与限制

已做离线几何和入口接入测试；未连接机器人，未在 URSim 或实际控制器上验证 URScript 编译、线程行为和制动效果。控制器软件版本未确认，部署前需要在对应版本验证。

零余量不等于零越界距离。软件只能在采样发现越界后开始停止，采样延迟、跟随误差和制动距离仍存在。该程序不能保证 TCP 物理上绝不越线，也不检查工具外形、连杆、碰撞或整段逆运动学可行性。`stopl(0.5)` 是软件停止参数，需结合设备和负载验证。

如需安全认证的强制限位，应按设备型号和控制器版本配置原生安全平面等安全功能。这份程序没有修改控制器安全设置。

边界计算仅有 1e-7 mm² 的浮点舍入容差（对应水平距离小于 1e-9 mm），没有工程余量；Z 下限不放宽。
