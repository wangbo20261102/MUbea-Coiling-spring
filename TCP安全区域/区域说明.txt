TCP Base 几何允许区域
单位：mm；坐标系：机器人 Base
XY：四个标定点投影围成的四边形，包含边界，余量 0 mm。
Z：z >= 0；上限未指定，区域向上开放。
标定点的原始 Z 仅作记录，不参与底面计算。

点 (x,y,z) 属于区域，当且仅当以下条件同时成立：
9.9 * x + (-587.5) * y <= 386036.42
-849.8 * x + (-14) * y <= 378284.76
-23.9 * x + (624.1) * y <= 126420.12
863.8 * x + (-22.6) * y <= 147212.24
z >= 0

注意：X/Y 的极值包围框不是允许区域，不能替代四条边约束。
JSON 中 z_max_mm=null 表示未指定上限，不代表机器人可无限向上运动。
这是 TCP 位置的几何约束，不是已验证的整机安全空间；未包含工具外形、机械臂连杆、障碍物、制动距离及可达性。
未向机器人发送指令，也未修改已有运动程序。
控制器若使用米：输入位置乘 1000 后再按本文件的毫米条件判断。
